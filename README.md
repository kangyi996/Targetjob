# 求职者智能体 Agent

一个面向求职者的智能体项目，目标是帮助用户完成从职位理解、简历匹配到面试准备的一系列求职任务。

本项目会在搭建过程中同步记录设计决策、实现过程、测试结果和面试表达要点，最终形成一个可以演示、解释和继续扩展的完整项目。

## 当前状态

项目初始化阶段，正在明确第一版 MVP 的目标和边界。项目将以 GitHub 仓库作为主要构建、版本管理和面试展示平台。第一版支持用户选择自己的求职身份，再生成更有针对性的分析和建议。
